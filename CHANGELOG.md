# Changelog

All notable changes to AthleteOS are documented here.

## [1.0.0] - 2026-07-20

### Added

- Production-ready Taekwondo Edition app structure.
- Local-first dashboard, profile, event watch, calendar, medals, vault, weight tracker, checklist, weather, and notifications.
- OpenAI-backed event and certificate scanning endpoints with graceful local fallback behavior.
- Professional documentation, GitHub templates, security policy, roadmap, and MIT license.

### Changed

- Refactored the browser app into data, utilities, assets, styles, and main entrypoint modules.
- Improved accessibility, responsive layout, empty states, loading states, buttons, sidebar, cards, and branding.
- Expanded package metadata and npm scripts.

### Fixed

- Removed duplicate root app script.
- Replaced malformed encoded UI glyphs with consistent inline icons.
- Updated imports and static asset paths for the new folder structure.
