# UI

AthleteOS uses a dark, focused desktop-first interface designed for repeated athlete and coach workflows.

## Design Principles

- Dense but readable operational layout
- Clear hierarchy for dashboard metrics and event status
- Consistent icon buttons and action labels
- Responsive navigation for mobile and tablet screens
- Visible empty, loading, success, warning, and error states

## Components

- Sidebar navigation
- Hero readiness panel
- Metric cards
- Event rows
- Calendar month grid
- Medal cards
- Document rows
- Modal forms
- Toast notifications

## Accessibility

- Semantic buttons for all actions
- `aria-live` toast updates
- Skip link for keyboard users
- Dialog labels and close controls
- Reduced-motion support
